Adds legs to the tank when you give it legs.

# Features:
* Spidertaaank, spidertaaank, does whatever a spidertank does...
* Spidercar? Only with the [car-equipment](https://mods.factorio.com/mod/car-equipment) mod!

# Compatibility
This mod is probably not compatible with other mods that modify the tank's functionality or appearance because of the limitations of the modding engine.

Note that this mod can be quite buggy and it isn't balanced in the slightest so I wouldn't recommend playing a serious game with it.

It should be safe to add this mod mid-save, but removing it will cause problems unless you take the exoskeletons out of your tanks beforehand.
